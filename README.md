## 🤖 AI 協作紀錄

### AI 協助的部分

1. **網站整體架構規劃** — 根據作業需求與個人資料，由 AI 建議單頁五區塊的資訊架構與呈現順序。

2. **視覺風格設計** — 根據提供的兩張參考圖（古典油畫 × 現代排版設計），AI 分析並提取配色（深褐底、磚紅、古典金）、字體選擇（Cormorant Garamond 等古典 serif）與版面語彙。

3. **HTML 結構生成** — AI 生成初版 HTML，包含導覽列、英雄區、時間軸、Tab 切換等語意化標籤。

4. **CSS 樣式撰寫** — AI 根據風格偏好生成 CSS 自訂變數、響應式格線、hover 動畫、進度條動畫等。

5. **JavaScript 功能** — AI 生成影格播放器（前/後按鈕切換）、Tab 切換、IntersectionObserver 捲動動畫、導覽列 Active 高亮等功能。

6. **文案補充** — 未來規劃的每日訓練計畫細節（速寫工具推薦、Anki 學習方法、動畫實作頻率）由 AI 根據目標補充。

### 自己的修改與判斷

1. **內容填寫** — 個人背景、使用工具清單、社群連結等真實資訊由本人提供，AI 無法自行創作。

2. **作品替換** — 作品集圖片為佔位框，需本人將實際作品圖片放入 `works/` 資料夾並依命名規則替換。

3. **影格數量調整** — 每部動畫預設的影格數（4–6 格）可根據實際作品圖片數量修改 HTML 中 `data-frames` 陣列。

4. **版面確認** — 在瀏覽器中實際開啟測試手機版與桌機版的顯示效果，確認導覽連結跳轉正常。

5. **個人照片** — 需自行放入 `images/profile.jpg`，並確認裁切比例（3:4 直式）符合設計框。

### 學習收穫

- 了解 CSS 自訂變數（CSS Variables）如何統一管理全站配色，修改主題色時只需改一處。
- 學習 `IntersectionObserver API` 的使用，取代傳統 scroll 事件監聽，效能更佳。
- 理解如何用 `data-*` 屬性讓 HTML 傳遞資料給 JavaScript，達成動畫影格播放器的效果。
- 練習 CSS Grid 的 `auto-fill + minmax` 語法，讓作品卡片自動在不同螢幕寬度下排版。

## 🔧 如何替換作品圖片

### 平面作品
將圖片命名為 `flat-01.jpg`、`flat-02.jpg`、`flat-03.jpg` 放入 `works/` 資料夾。

### 動畫影格
將動畫每格擷圖命名如下，放入 `works/`：

```
hs-anim-01-f01.jpg  （高中動畫1，第1格）
hs-anim-01-f02.jpg  （高中動畫1，第2格）
...
uni-anim-01-f01.jpg （大學動畫1，第1格）
...
```

若影格數量與預設不同，在 `index.html` 找到對應的 `data-frames='[...]'` 陣列，新增或移除路徑即可。
